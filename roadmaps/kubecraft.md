## 🛠 Phase 1: Linux & Networking Foundations
*Goal: Master the environment where Kubernetes lives.*

- [ ] **Linux CLI & Filesystem:** Navigating, `vim/nano`, permissions (`chmod`, `chown`), and process management (`ps`, `top`, `kill`).
- [ ] **Networking Basics:** Understanding TCP/IP, DNS, HTTP/S, and Load Balancing.
- [ ] **Shell Scripting:** Write a Bash script to automate a local backup or log rotation.
- [ ] **SSH & Security:** Key-based authentication and basic firewalling (`iptables`/`ufw`).

## 🐳 Phase 2: Containerization (The Docker Era)
*Goal: Package your Java/Spring Boot apps into portable units.*

- [ ] **Dockerizing Backend Apps:** Create multi-stage `Dockerfiles` for Java/Spring Boot (optimize for small image size).
- [ ] **Storage & Networking:** Work with Docker Volumes and Bridge Networks.
- [ ] **Docker Compose:** Orchestrate a 3-tier app (Spring Boot + PostgreSQL + Redis).
- [ ] **Image Registry:** Practice pushing/pulling from Docker Hub or GitHub Packages.

## ☸️ Phase 3: Kubernetes Core (The "KubeCraft" Pillars)
*Goal: Moving from running containers to orchestrating them.*

- [ ] **Local Lab Setup:** Install `Minikube`, `Kind`, or `K3d` on your laptop.
- [ ] **The "Big Four" Objects:** - [ ] **Pods:** Lifecycle and debugging.
    - [ ] **Deployments:** Rolling updates and rollbacks.
    - [ ] **Services:** ClusterIP, NodePort, and LoadBalancer.
    - [ ] **ConfigMaps & Secrets:** Injecting environment variables into your backend.
- [ ] **Storage:** PersistentVolumes (PV) and PersistentVolumeClaims (PVC).

## 🚀 Phase 4: Advanced K8s & Production Operations
*Goal: Making the cluster "Enterprise-Ready".*

- [ ] **Ingress Controllers:** Set up NGINX Ingress to route traffic to your services.
- [ ] **Helm:** Use Helm to package your apps and install 3rd party tools (like Prometheus).
- [ ] **Monitoring & Logging:** Deploy a Prometheus/Grafana stack to see your app's health.
- [ ] **HPA:** Set up Horizontal Pod Autoscaling based on CPU/RAM usage.

## 🔄 Phase 5: CI/CD & The DevOps Pipeline
*Goal: Automate everything. No manual `kubectl apply`.*

- [ ] **GitOps Workflow:** Learn the difference between Push (GitHub Actions) and Pull (ArgoCD) models.
- [ ] **GitHub Actions:** Build a pipeline that runs tests, builds a Docker image, and pushes it.
- [ ] **ArgoCD:** Automate the deployment of your K8s manifests whenever you push to Git.

## ☁️ Phase 6: Infrastructure & Homelab
*Goal: Real-world infrastructure experience.*

- [ ] **Cloud Provider:** Set up a free-tier account (AWS/Azure/GCP) and deploy a managed K8s cluster (EKS/AKS/GKE).
- [ ] **Infrastructure as Code (IaC):** Use Terraform to provision a simple VM or VPC.
- [ ] **Homelab:** Use your local machine or a spare laptop to run a "production-like" cluster using K3s.

## 💼 Phase 7: Career & Portfolio Layer
*Goal: Getting noticed by recruiters.*

- [ ] **The "Evidence" Portfolio:** Create a GitHub repo for each major project (e.g., "Full-Stack Deployment on K3s").
- [ ] **LinkedIn Optimization:** Update your profile with K8s/DevOps keywords.
- [ ] **Technical Writing:** Write a blog post (Dev.to/Medium) explaining how you solved a specific K8s networking issue.
- [ ] **Interview Prep:** Practice "Behavioral" and "Technical" scripts for DevOps roles.
